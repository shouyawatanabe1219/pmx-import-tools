# PMX ポーズ・アニメーション作成ツール

Unity 6.3 LTS (6000.3.8f1) で検証した、既存のPMXインポーター向け追加機能です。

## 開く

Unity のメニュー **Tools → PMX → ポーズ・アニメーション作成**。
シーンへモデルを配置し、対象と新しい作業データを指定してください。
閉じた場合は同じメニューから開いてください。

## アニメーションを作る

1. 「シーンのモデル」に、Hierarchy のミクのルートを指定します。
2. 「新しい作業データ」で `.asset` を作るか、既存の作業データを指定します。新規作成時のポーズがフレーム0になります。
3. フレーム0でボーンの位置・回転・大きさや、表情の強さを調整して「このフレームに記録」。
4. フレーム30など別のフレームへ移動し、別のポーズにして記録します。30FPSなら30フレームが1秒です。
5. 「プレビュー再生」で確認します。位置・大きさ・表情は直線補間、回転はQuaternionで補間します。
6. 「データを保存」で作業データを保存します。キーの記録・削除・設定変更はUndoで戻せます。
7. 「.anim に書き出してモデルへ設定」でUnity標準のAnimationClipを保存します。シーンを保存してPlayすると、追加された `PmxAnimationPlayer` が再生します。

同じフレームに記録すると、そのフレームのポーズを置き換えます。未記録のポーズ調整は、フレームを移動すると失われるので、移動前に記録してください。フレーム0は削除できません。ループさせたい場合は、終了フレームにも開始ポーズを記録してください。

## リグを直接操作する

**GameビューではなくSceneビュー**を開きます。「リグ全体を表示」でモデル全体が見えます。

1. リグの水色の点をクリックしてボーンを選びます。選択した点はオレンジ色になります。
2. **W**で移動、**E**で回転、**R**で拡縮。ハンドルをドラッグするとモデルが変形します。
3. 手首や足首をWで移動すると、編集用2ボーンIKで肘・膝も曲がります。「手首・足首の移動で腕・脚も曲げる (IK)」をオフにすると、選択ボーンだけを移動します。
4. 「操作したポーズを現在のフレームへ自動記録」は初期設定でオンです。Sceneのドラッグを終えると、そのフレームにポーズを記録します。数値欄や表情スライダーの変更も記録します。手動で記録したい場合はオフにしてください。
5. 別のフレームに移動して次のポーズを作り、プレビューします。記録したポーズの変更はUndoで戻せます。

最初は体・腕・脚の主要ボーンだけを表示します。「指・髪・補助ボーンも表示」で全ボーンを表示できます。プルダウンから選んだ補助ボーンは、簡易表示中も表示します。

Tda式ミクの脚では、実際のスキニングに使われる「足D」「ひざD」「足首D」を主要リグに使います。手首・足首の向きと手足の長さを保ちながらIKで曲げ、届かない目標は届く範囲に収めます。IKの結果もボーンのポーズとしてキー・クリップに記録するため、再生時に追加のIKコンポーネントは不要です。

## モデルの微調整

ボーンの位置・大きさと頂点モーフを調整できます。「現在の調整をシーンに確定」は、ポーズをシーンのモデルに反映します。Undoで戻せます。

プレビュー中の変更は、ウィンドウを閉じる・シーンを保存する・Playを開始する・スクリプトを再読み込みする際に元へ戻ります。シーンに残したい調整は、先に「現在の調整をシーンに確定」を押してください。確定とフレームへの記録は別の操作です。

## 物理と表情

「髪・スカートなど物理ボーンは書き出さない」が初期設定です。PMX剛体のモード1/2が駆動するボーンをアニメーションから除外し、既存の `PmxPhysicsController` に任せます。そのボーンの調整も書き出す必要がある場合は、この設定をオフにし、再生中は物理との競合を避けるためモデルの `PmxPhysicsController.simulate` をオフにしてください。

編集プレビューでは物理を実行しません。髪やスカートが動く様子はPlayで確認します。

`PmxAnimationPlayer` は再生中に `PmxFaceController` を一時停止し、記録したBlendShapeを使います。Stopまたはコンポーネント無効化で、元の有効状態に戻します。Pauseでは記録した表情を維持します。同じモデルのAnimator / Animationが有効な場合は、競合を避けるため警告を出して再生を開始しません。書き出したクリップはAnimatorでも利用できますが、その場合はPmxAnimationPlayerを無効にし、表情の上書きにも注意してください。

## 現在の範囲

- ボーンの直接操作と手首・足首の編集用2ボーンIKに対応します。PMX固有のIKチェーン・関節制限・付与の自動適用、再生中の足接地、自動リターゲット、頂点・トポロジー編集、PMXファイルへの書き戻しは含みません。
- 編集用IKは手首・足首と対応する腕・脚の名前・階層を認識できるモデルで使えます。Tda式ミクと標準的な英語名の手足に対応します。未認識のボーンは直接移動します。
- 作業データとクリップは、同じボーンパス・BlendShape名を持つモデル用です。
- 表情は実際のBlendShapeを直接編集します。グループモーフ専用スライダーはありません。
- 再生時間は最大3600フレーム、FPSは1〜120です。
- 元のPMX、頂点、マテリアル、既存の物理スクリプトは変更しません。シーンに確定する調整は個々のインスタンスに保存します。
- 大きな体型変更で剛体・ジョイントの配置が合わなくなる場合は、それらも調整してください。剛体形状の自動再計算は行いません。

## 別プロジェクトへの導入

既存の `PmxImporter` があるプロジェクトに、`Runtime/PmxAnimationPlayer.cs` を追加し、`Editor` 内のファイルを同じEditorサブフォルダーへまとめて配置してください。`.meta` も一緒にコピーします。既存PMXインポーターのファイルを上書きする必要はありません。

## 検証

リグ追加後は、主要ボーン表示・ボーン選択・両手両足のIK・到達範囲・手足の長さと向きの維持・実メッシュの変形・キーとクリップへの変換・プレビュー復元の38項目も検証しました。

実際のTda式初音ミクV4Xのコピーを使い、24項目を検証しました。ボーン・表情の補間、同一フレーム置換、物理ボーン除外、Unityクリップの保存・再読み込み・サンプリング、UI Toolkitの生成、プレビュー復元、Undo、再生コンポーネントのSeek/Stopなどを確認しています。検証結果は [Validation.md](Validation.md) を参照してください。

書き出しにはUnity公式API [AnimationUtility.SetEditorCurve](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/AnimationUtility.SetEditorCurve.html)、再生には [AnimationClip.SampleAnimation](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/AnimationClip.SampleAnimation.html) を使っています。
