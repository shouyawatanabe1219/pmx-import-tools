# 0.2.0の検証

Unity 6000.3.8f1 / URP 17.3.0 / Windows Editorで確認しました。

- RuntimeとEditorを別アセンブリとしてコンパイル成功。RuntimeのUnityEditor依存なし。
- UPMローカルパッケージとして登録、実際に新規デコーダーと物理クラスがロードされたことを確認。
- PMX生成データによる294項目：1/2/4バイト索引、UTF-8/UTF-16、頂点・ボーン・モーフ・材質、3形状・3駆動方式、ジョイント、衝突除外、停止・再開など。
- 第三者モデルで120剛体・160ジョイント・63頂点モーフを読み込み。検証モデルは配布しません。
- 本体との衝突除外367項目：床・別Rigidbodyとの衝突維持、既存除外の復元、動的本体と床で10秒シミュレーション。終了時の本体速度0。
- Play中の独立PhysicsSceneで各500ステップ：モデル50cm移動、90度回転、センターボーン50cm移動後、スカート末端の最大上昇は初期位置より約-0.002m、最大速度は約0.028m/s以下。
- ポーズ・AnimationClip24項目：位置・回転・表情補間、記録、Undo、保存と再読み込み、実行時再生、UI Toolkitウィンドウ。
- リグ38項目：両手両足のIK、長さ・方向維持、実メッシュ変形、記録・クリップ出力・復元。
- ZIP26項目：UTF-8/Shift-JIS日本語名、PMX読み込み、不要コードの除外、再読み込み、パス検証。
- 球面テクスチャ・材質・シェーダー16項目：8/24/32bit BMPの上下方向、PNG、材質抽出と外部リマップ、URPシェーダーのエラーなし。

すべてのPMXモデル・操作・描画環境で同じ挙動を保証するものではありません。物理制限の近似と未対応機能はREADMEおよびPhysics.mdに記載しています。

Tests~/PmxValidation.cs は合成PMXによる294項目を再実行するEditor用コードです。検証用プロジェクトのAssets/Editorへコピーして、Tools → PMX → Tests → Core Regressionを実行します。通常の導入時には不要です。
