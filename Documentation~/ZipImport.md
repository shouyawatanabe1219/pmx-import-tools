# PMXモデルをZIPごと読み込む

Unity 6.3 LTS (6000.3.8f1) の既存PMXインポーターへ追加済みです。

## 使い方

- **ZIPをProjectビューのAssetsへドラッグ**すると、PMXが入っているZIPを自動で展開・読み込みします。
- または **Tools → PMX → ZIPからモデルを読み込む** から、DownloadsなどにあるZIPを選びます。元のZIPをAssetsへコピーせずに読み込めます。
- AssetsにあるZIPの右クリックメニュー **PMX → 選択したZIPを読み込む** からも読み込めます。

展開先は `Assets/MmdZipImports/<ZIP名>`。ZIP内のフォルダー構造と日本語名を保ち、テクスチャを先にインポートしてからPMXを読み込みます。展開されたPMXをHierarchyへドラッグすれば、既存と同じモデルとして使えます。ポーズ作成ツールにも、シーンへ置いたモデルを指定できます。

PMXが1つなら読み込み後にそのモデルを選択します。複数なら展開フォルダーを選択するので、使用するPMXを選んでください。シーンへの配置は自動では行いません。

## 再読み込み

Assets内の同じZIPは、内容が変わっていなければRefresh・Reimportで重複展開しません。内容が変わった場合、または手動で読み込みを実行した場合は、新しいフォルダーへ展開します。既に調整したモデルを上書きしません。

ZIPを削除しても、展開済みのモデルは残ります。読み込み履歴はLibraryに保存するため、Libraryを削除した場合は自動展開が再度行われることがあります。

## 対応範囲

- UTF-8とShift-JISの日本語ファイル名、複数PMX、サブフォルダー、バックスラッシュのパス。
- PMX、一般的な画像・球面マップ、説明文書、VMD/VPD、音声ファイルを展開します。VMD/VPDの展開は再生対応を意味しません。
- ソースコード、実行ファイル、DLL、Unityのmetaファイル、入れ子のZIPなどは展開しません。
- ZIP内にPMXがなければ、自動展開しません。
- 通常の非暗号化ZIP用です。分割ZIP・ZIP64・パスワード付きZIPは対象外です。ファイル数10000件、1ファイル512MB、展開合計2GBが上限です。
- ZIP内のリンク、展開先の外へ出るパス、同名ファイルなどは拒否します。
- Editor向け機能です。ゲーム実行中にZIPを読み込む機能は含みません。

元のPMXインポーターや物理・ポーズ作成のコードは変更しません。読み込みに失敗した場合はConsoleを確認してください。Assetsへ展開した後の失敗では、修正・再インポートできるようにファイルを残します。

## 別プロジェクトへの追加

既存のPMXインポーターがあるプロジェクトのEditorフォルダーへ、`PmxZipImport.cs` と `.meta` をコピーしてください。

## 検証

0.2.0ではUTF-8/Shift-JISの日本語名、モデル読み込み、再読み込み、不要コードの除外、パス検証を26項目で確認しています。球面テクスチャ・材質は別途16項目で確認しました。詳しくは [Validation.md](Validation.md) を参照してください。
